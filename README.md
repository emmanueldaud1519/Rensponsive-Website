# Iyunga Secondary School Website

This is a complete static website for Iyunga Secondary School built using only HTML, CSS, and vanilla JavaScript.

## Project structure

- `index.html` — main page structure and all sections
- `css/styles.css` — design, layout, colors, responsiveness, and animations
- `js/script.js` — mobile menu, scroll effects, form interaction, and dynamic footer year

## Run the site locally

Open the folder in VS Code, then either:

1. Use a local web server with Python:
   ```bash
   cd c:/Users/Administrator/Desktop/School_iyunga
   python -m http.server 8000
   ```
2. Open your browser and visit:
   ```text
   http://localhost:8000
   ```

## Deployment

This site is ready for GitHub Pages or any static hosting service because it contains no backend or build step.

### GitHub Pages quick steps

1. Create a GitHub repository.
2. Upload these project files to the repository root.
3. In GitHub, go to Settings -> Pages.
4. Choose the main branch or a deploy folder.
5. Save the settings and use the generated Pages URL.

## Customization

You can easily replace the placeholder text, images, and contact details with the real school information later.
